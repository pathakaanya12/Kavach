HOW TO DEPLOY (Aanya)
Needs: gcloud installed and logged in (gcloud auth login) and one Google Cloud project with billing or credits enabled.
Run from this folder:  ./deploy_cloudrun.sh
Defaults: region asia-south1 (Mumbai), service name kavach. The script enables the needed APIs, reads .env and sets the values as Cloud Run environment variables, builds with the Dockerfile and deploys. The .env file itself is kept out of the container image by .dockerignore.
Local run instead:  ./run.sh   (or run.bat on Windows), then open http://127.0.0.1:8000
